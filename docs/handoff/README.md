# docs/handoff — 交接报告目录

每张卡完成后，执行子 Agent 必须在此目录提交 `TC-XXX.md`，按**七段式**填写；缺任何一段视为未交付。

七段式定义见《ResumeCraft 开发任务分工》V1.2 §4：

1. 任务 ID 与完成内容（对照任务卡「任务内容」逐条）
2. 修改/新增文件清单（绝对路径，标注新增/修改/删除）
3. 运行的命令与测试结果**原文**（未运行的测试不得声称通过）
4. 未解决问题
5. 与 PRD 不一致处（如有，必须显式列出，不得隐瞒）
6. 下一步建议
7. 任务卡状态更新

归档规则：
- 命名固定 `TC-XXX.md`（TC-013a 写成 `TC-013a.md`），不建子目录、不加日期后缀。
- 我（阿U）的验收结论追加在**同一文件**末尾的「验收记录」小节，标明验收时间、执行的命令、逐条 FR 判定、结论（通过/打回第 N 次）。
- 交付与验收不拆两个目录（2026-10-23 评审 Q2 决策：合一）。
