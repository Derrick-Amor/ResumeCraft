## 八、今天踩过的坑（新对话务必避开）

| 坑 | 表现 | 规避 |
|---|---|---|
| 用间接指标替代直接证据 | 行数当词表、computedStyle 当字体加载、记忆当实测、目测当计算 | 判据必须能证伪，且跑命令贴输出 |
| grep 判拼接类名 | `:class="{ 'side__tab--on': ... }"` 拼出来的类 grep 不到 | 类名判定用运行时 DOM |
| 文案转述 | 模板 meta/desc 我转述错 3 处 | 文案从 HTML 原文 grep |
| 「听说已有」不验证 | `moveComponentTo` 不存在，拖拽空转而四门全绿 | 接线前 grep 一次 |
| 破坏性自检用"第一次出现" | 替换 `padding: 0` 动到了 `.topbar` | 用精确锚点 |
| 补丁 replace 静默失败 | 代码继续编译，引用时才炸 | 每次 replace 加 assert |
| 消息交叉导致误判 | 我核验快照早于工程师写入，误报"没落地" | 先跑对方给的命令再下结论 |
