# ResumeCraft 需求摘要（面向后续开发 Agent）

> 依据 PRD V1.3（2026-10-22）。本文件是**快速上下文**，不是 PRD 缩写；与 PRD 冲突时一律以 PRD 为准，边界以《边界检查表》为准，任务以 TASKS.md 为准。

## 1. 一句话定位

Web-first 简历编辑与自动排版应用：结构化编辑 → 确定性排版 → 可靠导出。核心卖点＝**改内容不错位**；差异化＝**跨应用可继续编辑**（自产 DOCX 埋结构标记，可反向无损导入）；能力标签＝**简历画板**（三层图层）。不做通用文字处理（PRD 1.1/1.2、4.2）。

技术栈已锁定，不得更换：Vue3 + TS + Vite + Pinia + Zod；本地优先 IndexedDB；PDF 用 pdf-lib（中文字体必须 TTF）；DOCX 用 docx 库；导入用 mammoth + pdfjs-dist（PRD 13.1）。

## 2. 用户与语言轨

- 群 A 大学生/应届（MVP 核心）；群 B 有经验求职者（多版本用"另存为"兜底，FR-DOC-005 属 P1）；群 C 已有简历迁移者（不承诺完美还原）；群 D 求职辅导（Future，不承诺）。
- **双轨**：`languageTrack` 决定字段可选性。中文轨可有照片、政治面貌；英文轨**无照片位、无政治面貌**，含 LinkedIn/作品链接位，模板可默认隐藏自我评价。差异必须写在组件声明里，禁止在 UI 散落 `if (languageTrack === 'en')`（PRD 2.1、8.1；CONTRACT §3）。

## 4. MVP 范围（硬边界）

MVP ＝ **P0 全部 + DOCX/PDF 导入**；AI 建议层整体后置 P1（PRD 3.1）。PRD 3.1 的 16 项必含：桌面浏览器跑通核心流程；五区域布局；新建/编辑/保存/重开；中英双轨组件；单栏+换行；页边界/溢出/分页；**4 套自设计模板**；模板切换不丢内容；PDF 导出（含导出前检查+回读冒烟）；DOCX 导出（明示"可编辑副本"）；DOCX 导入；文本型 PDF 导入；撤销重做；IndexedDB 持久化+JSON 备份；关键流程测试；错误提示与已知限制。

## 5. 边界四象限（详见《边界检查表》）

- **做**：结构化编辑、单栏布局、分页溢出、4 模板、PDF/DOCX 导出、DOCX/PDF 导入、undo、本地持久化、导出前检查。
- **后置 P1**：AI 建议、多栏（FR-LAY-009）、模板搜索收藏（FR-TPL-004）、多版本（FR-DOC-005）、视觉层级/密度（FR-QA-003/004）、人工审核状态（FR-QA-006）。
- **暂缓 P2/Future**：扫描件 OCR、批量处理、社区化模板市场（创作者经济）、多语言界面、云同步、求职辅导批量工具。
- **明确不做**：复刻 Word/WPS；演示/海报；100% 还原任意 DOCX/PDF；扫描件识别；多人实时协作/企业后台（平台自用运营后台 FR-OPS-001 属 P2 例外）；PWA/离线；手机编辑；后端（M5 前）。

## 6. 冲突裁决（唯一顺序）

**数据完整性 > 布局合法性 > 用户确认 > 可验证性 > 视觉效果**（PRD 4.8）。裁决前先出冲突说明，不得先动代码。

## 7. 不能碰的 10 条红线

1. 静默删/改用户内容——溢出不自动删、不自动压缩，压缩需用户确认（FR-LAY-011、4.8）。
2. 静默丢弃未知组件或未识别块——保留并标 unknown，或进 `pending[]`（8.3、FR-IMP-008、CONTRACT §2/§7）。
3. 导入失败覆盖原文件（FR-IMP-007）。
4. 测量依赖 DOM 布局，或 DOM 读数未经对照验证（CONTRACT §4）。
5. 布局函数读写 store/DOM/时间/随机数——必须纯函数，同输入同 `inputHash`（FR-LAY-010、CONTRACT §5）。
6. 业务核心直接调 IndexedDB / File System Access API——只经 StorageAdapter（CONTRACT §6）。
7. PDF 用 OTF/CFF 字体（Chrome 不渲染）；DOCX 结构标记不升版本号（13.1#10、CONTRACT §7）。
8. 导出跳过质量检查，或 blocking 非空仍静默产出文件（FR-EXP-003、CONTRACT §8）。
9. 降级不告知：字体降级、File System Access 降级、标记降级均须显式标记并由 UI 呈现（CONTRACT §11）。
10. 擅自新增 `src/` 一级目录、改 schema、加依赖——目录以任务分工附录 A 为准（11 个），schema 变更须回写 PRD 8 章。
