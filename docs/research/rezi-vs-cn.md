## 一、Rezi 是一个什么生意

### 1.1 一句话

**"帮你的简历通过机器筛选"的订阅制工具**，靠 ATS（Applicant Tracking System，企业招聘管理系统）叙事建立权威感，用评分把"改简历"从主观变成可量化的进度条。

官网原话：`Ranked #1 AI Resume Builder by Forbes` / `You're not getting ghosted by humans` / `If your resume isn't structured correctly… it's filtered out. Silently. Without explanation.`

### 1.2 产品结构：Build → Score → Target

| 环节 | 具体功能 | 用户感知 |
|---|---|---|
| Build | 20+ 模板、实时排版、AI 写作/改写 bullet | "5 分钟出一份像样的简历" |
| Score | Rezi Score（1–100，23 个检查点，分板块打分、红黄指示） | "我知道自己差在哪" |
| Target | 粘贴 JD → 关键词扫描 → 提示缺失词 → 一键补进简历 | "同一份简历能对着岗位改" |
| 延伸 | 求职搜索/投递追踪、AI 模拟面试、Cover Letter、Chrome 插件、移动 App、MCP（在 Claude/ChatGPT 里管简历） | "一站式，不用换来换去" |

### 1.3 定价与转化设计（这是最值得学的部分）

| 计划 | 价格 | 关键限制 |
|---|---|---|
| Free | $0 | **1 份简历 + 3 次 PDF 下载**，标准模板，可用基础 AI |
| Pro | **$29/月** | 无限简历/下载、全部 AI、每月 1 次人工简历点评 |
| Lifetime | **$149 一次性** | Pro 全部功能，不含每月人工点评 |

**四个精心的设计**：

1. **免费版"够用但会卡住"** —— 能完整做出一份简历并下载 3 次。不是试看，是"真给你用"，但求职者往往要投 10–50 个岗位，第 4 次下载就撞墙。**这一刀切在"使用频率"上，不切在"功能"上**，所以用户是在"已经投入了时间"之后才被要求付费。
2. **$149 终身是真正的主力（推断）** —— 一次求职周期通常 1–3 个月，$29×2 = $58，用户会算账；$149 一次性 ≈ 4–5 个月月费，看起来"一次买断更划算"，实际客单价远高于短期订阅。**用订阅做价格锚，用终身做成交。**
3. **30 天无条件退款 + 不要信用卡就能开始** —— 把"尝试"的心理成本压到零。
4. **人工点评做溢价** —— Pro 每月 1 次真人简历点评（估值 $8），把"AI 工具"抬成"服务"。

### 1.4 它到底解决了什么痛点（为什么有人愿意付钱）

| 痛点 | Rezi 的解法 | 为什么值 $29 |
|---|---|---|
| **被系统静默筛掉，不知道为什么** | ATS 兼容模板 + 关键词扫描 + 评分 | 这是"信息黑箱"，用户愿意为"看得见的原因"付费 |
| **不知道简历哪里不好** | 23 检查点分板块打分、红黄标注 | 把模糊的"感觉不好"变成具体待办 |
| **投一个岗要改一小时** | 贴 JD → 自动识别缺词 → 一键补 | 时间成本直接换算成钱（官网用户原话：1–2 小时→15 分钟） |
| **怕自己写得"像 AI"** | 强调"专用工具而非通用聊天机器人" | 对抗 ChatGPT 免费替代的心理防御 |
| **求职焦虑，需要一个确定的流程** | 找岗→改简历→投递→模拟面试闭环 | 卖的不是文档，是"我在系统地找工作"的掌控感 |

**核心结论**：Rezi 卖的不是"排版"，是**确定性**。排版只是入口，真正被付费的是"我知道为什么被拒 / 我知道下一步改什么"。

### 1.5 第三方怎么看它的短板

- 免费版**3 次 PDF 下载**是最集中的抱怨点，很多人是"做完才发现导不出"。
- AI 写作在**非技术岗/非主流岗位**上明显泛化，出来的句子空。
- **没有移动 App**，编辑体验是桌面优先。
- 模板刻意极简（为过 ATS），**创意/设计岗不适用**。
- 官网宣称 **62.18% 面试成功率**（对比行业均值 ~3%），第三方评测直接点名"没有方法论支撑的数字"。这是**营销话术**，不是可验证的产品能力。

> 对我们的意义：**"效果数字"是可以吹的，但吹了会掉信任。** 要么给方法学，要么别提。

## 二、中国求职的结构性差异（这部分决定我们能不能照搬）

### 2.1 最关键的一条：中国没有"一份 PDF 进 ATS"的单一链路

美国：投递 = 上传一份 PDF → 企业 ATS（Workday/Greenhouse/Lever）解析 → 关键词匹配 → HR 看解析后的结构化字段。

中国（以 BOSS 直聘为代表的直聊模式）是**双轨制**：

| | 在线简历 | 附件简历 |
|---|---|---|
| 生成 | 平台强制字段（工作起止、技能标签、求职意向） | 自己做的 PDF/DOC |
| 谁能看 | **HR 浏览主页即可见，无条件公开** | **必须双方已沟通 + HR 点"发简历"才能拿到** |
| 作用 | **参与平台算法匹配与初筛** | 深度评估、面试参考、打印 |
| 排版 | 平台决定，改不了 | 自己定 |
| 更新 | 改完即时生效 | 改完要重发，**容易出现版本混乱** |

**推论 1：Rezi 的"A 端叙事"在中国只对一半。** 中国的"算法初筛"发生在**平台内的在线简历字段**上，不在我们导出的 PDF 上。把"过 ATS"当作核心卖点，在国内会被 HR 一眼看穿。

**推论 2：真正的痛点是"两份简历的一致性"。** 求职者要维护在线精简版 + 附件精排版两份内容，字段、时间、职位必须对得上（对不上会被追问）。**这是国内独有的、尚未被很好解决的问题。**

**推论 3：附件简历的第一读者常常是手机。** HR 在通勤/会议间隙刷人，PDF 在手机上缩放、错行、表格塌掉是常态——这正是"排版错位"在国内的高频场景，比 A4 打印场景更刚需。

### 2.2 国内渠道决定了"简历要长什么样"

- 校招：企业网申系统（自有表单）+ 附件上传，字段多、格式死。
- 社招：BOSS/猎聘/智联/前程无忧 直聊，先看在线简历，再要附件。
- 国企/体制内：仍看政治面貌、党员、籍贯、照片；**照片是硬需求**（国外简历放照片是禁忌，国内不放反而奇怪）。
- 外企/留学：中英双语，英文版要符合国外规范（无照片、无政治面貌）。

**所以"中英双轨"在国内不是加分项，是刚需；而且中文轨和英文轨的字段差异是结构性的，不是翻译问题。**

### 2.3 国内竞品盘面（价格与定位）

| 产品 | 定位 | 价格带 | 特点 |
|---|---|---|---|
| 超级简历 WonderCV | 老牌轻量工具 + HR 人服 | 月卡 ~18–59、年卡 ~79.9–198、终身 ~99–128；**1v1 简历优化 ¥189 起/月** | 5000+ 模板、WonderAI、ATS 兼容检测；商业化引导重，核心功能锁会员 |
| 100分简历 | 内容表达弱的人 | 未核实 | 3000+ 岗位模板、导入识别 98%、9 步向导 + 岗位关键词推荐 |
| 职徒简历 | 学生党、极简 | 未核实 | 上手快，AI 能力轻 |
| 职悟空（智联系） | 应届生全流程 | 免费 | 与智联绑定，重流程轻工具 |
| AI 简历姬 | JD 为中心 | 7 天 25 元 | 匹配度评分、关键词缺口清单、投递-面试-复盘闭环 |
| 豆包 / 通用大模型 | 纯文本润色 | 免费 | 不做模板排版，但"改写成 STAR"已经够用 |

**价格锚点对比（重要）**：

- Rezi 终身 **$149 ≈ ¥1070**
- 国内终身 **¥99–128**
- 国内月卡 **¥18–59**
- 国内真正赚钱的是**人服**：HR 1v1 优化 ¥189–199 起、代投、面试辅导

**结论：国内"工具订阅"的天花板很低（免费替代品太多），钱在"人 + 结果"那一侧。**

## 三、共同点 / 不同点

### 3.1 设计上的共同点

1. **都把"模板"当入口**——因为用户第一反应是"我要一个好看的模板"，没人一开始就说"我要 ATS 兼容"。
2. **都在做"评分/诊断"**——Rezi Score、超级简历 AI 打分、AI 简历姬匹配度。**诊断是转化的钩子**：先让你看到问题，再卖解决方案。
3. **都在往"全流程"扩**——简历 → 求职 → 面试，因为单点工具留存差、复购低。
4. **都克制成"单栏、少色、重内容"**——因为要过机器/要被 HR 快速扫读。

### 3.2 设计上的不同点

| 维度 | Rezi | 国内主流 |
|---|---|---|
| 排版自由度 | 刻意极简，牺牲设计感换解析率 | 模板花哨、视觉优先（国内 HR 不吃 ATS 那套） |
| 首屏信息密度 | 一页塞满，无照片 | 常带照片、留白更多、模块化 |
| 移动端 | 无 App，桌面优先 | 小程序/App 为主，手机上就能改 |
| 语言 | 英语单轨（模板有双语但弱） | 中英双轨是卖点，但多是"翻译"而非"重写" |
| 核心指标 | ATS 解析率、Rezi Score | 模板数量、AI 生成速度、导出是否免费无水印 |

### 3.3 经营模式的不同点

| | Rezi | 国内 |
|---|---|---|
| 主收入 | 个人订阅 $29/月 + 终身 $149 | 会员（¥18–128）+ **人服（¥189 起）** + 代投 |
| 免费策略 | 功能全给、用量卡死（1 份/3 次下载） | 功能卡死（下载/中英切换/好模板锁会员）、用量不限 |
| 信任来源 | Forbes/Trustpilot/用户数 | HR 背书、真人导师、社群 |
| 转化逻辑 | 先做出成品 → 导出时付费 | 先看到模板 → 下载时付费 |
| 客单价 | 高（≈¥200/月，≈¥1070 终身） | 低（工具），靠人服拉高 |

> 一句话：**Rezi 卖"确定性"，国内卖"省事 + 有人管"。**

## 四、对 ResumeCraft 的定位建议

### 4.1 不要照抄的三件事

1. **别把"过 ATS"当核心卖点。** 中国的筛人发生在平台在线简历上，不在你的 PDF 上。讲了会被懂行的 HR 当外行，讲了也验证不了。
2. **别做"模板数量"军备竞赛。** 超级简历 5000+、100分 3000+，我们不可能赢，且模板是低壁垒、高维护成本。
3. **别指望工具订阅赚钱。** 国内工具价格锚点被免费产品钉死在 ¥0–128，而人服能收 ¥189–499。

### 4.2 值得押的三个差异点（都是国内特有、现有产品没做好的）

**① 一份内容 → 两个产物：在线精简版 + 附件精排版，且保证字段一致**

- 痛点真实：双轨制导致的版本混乱，是每个认真找工作的人都会遇到的。
- 现有产品都没解决：模板工具只管 PDF，平台只管在线字段，中间靠人脑对。
- 我们的技术底座（结构化文档模型）天然支持：**同一份 Document，两种渲染输出**。这是架构上的先天优势，不是补丁。

**② 手机端不崩版**

- HR 在手机上看附件是高频场景。现有产品的 PDF 在手机上缩放、表格塌陷、分栏错位。
- 我们的确定性布局引擎可以把"手机预览"做成一个受控输出（不是缩放 PDF，而是按手机宽度的重排视图）。
- 这一条能做成**可演示、可截图传播**的东西——比"过 ATS 90%"实在得多。

**③ 中英双轨的"重写"而非"翻译"**

- 国内产品的双语基本是机翻 + 换模板。英文简历的规范（无照片、无政治面貌、动词开头、量化结果）跟中文是两套逻辑。
- 我们的组件层已经预留 `languageTrack` 字段裁剪（TC-005 契约），做成"一键切换语言轨并按目标语规范重排"是有壁垒的。

### 4.3 变现路径（按"先验证、后扩张"排）

| 阶段 | 主张 | 依据 |
|---|---|---|
| P0 | **免费 + 导出付费**（导出前检查是天然付费点） | 借鉴 Rezi"做出成品再收费"，但别卡在"下载次数"上（国内用户会直接找免费替代），卡在**"导出前的问题诊断与一键修复"** |
| P1 | **付费诊断/人工点评**（¥39–99 一次） | 国内已验证能收钱的是人服；我们先用 AI 做半自动诊断降低边际成本 |
| P2 | 模板市场/创作者分成 | 你的决策汇总里已规划，但这是网络效应生意，人少时无效 |
| 不建议 | 订阅制月费 | 国内月费续订率低，求职是低频事件，月费会逼用户"用完就退" |

### 4.4 必须提前想清楚的三个风险

1. **免费替代品**：豆包/WPS/夸克 能覆盖 60% 的"改文字"需求。我们只能在"排版确定性 + 双产物一致"这些它们做不到的地方赢。
2. **低频**：一个人一年可能只用 1–2 次。**低频产品必须高客单或高频陪伴**，两者都不占就会死。我们目前只能选高客单（诊断/人服）。
3. **大厂下场**：BOSS/智联自己做简历工具是零成本的（他们掌握在线简历数据）。**我们的生存空间必须在"跨平台"**——不绑定任何一家招聘平台，服务同时投多个渠道的人。

## 五、建议的下一步验证（不要拍脑袋定价）

| # | 要验证的假设 | 怎么验（低成本） | 判定标准 |
|---|---|---|---|
| V1 | "双产物一致性"是不是真痛 | 找 10 个最近求职的人，问他们怎么维护在线/附件两份简历，有没有对不上过 | ≥6 人说"遇到过"才成立 |
| V2 | 手机端崩版是不是高频 | 收集 20 份不同来源的简历 PDF，在手机宽度下截图统计崩版率 | ≥30% 崩版才值得做成卖点 |
| V3 | 导出前诊断愿不愿意付费 | 做一个假门（假付费墙），看点击率 | ≥8% 点"付费解锁"再谈定价 |
| V4 | 中英双轨谁在用 | 统计校招/外企/留学三个渠道的需求占比 | 决定 TC-005 语言轨的优先级 |

> 这四条都不需要写代码，一周能做完。**在写 TC-005 之前做，比写完再发现方向错了便宜。**

## 六、和现有 PRD 的关系（需要你拍板的冲突点）

| 现有 PRD 表述 | 本文建议 | 冲突 |
|---|---|---|
| 核心卖点＝"改内容不错位"（排版确定性） | 保留，但要补"双产物一致"作为第二卖点 | 需在 PRD 1.2 增补 |
