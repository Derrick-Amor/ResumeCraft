## 4. 4.4 文件与数据边界（保存三档 3 条 + 约束 3 条）

- [ ] 档 1 自动保存：文档 JSON 定期写入 IndexedDB 并显示保存状态，全部浏览器（P0）（来源：4.4）
- [ ] 档 2 覆盖写回：仅 Chromium，经 File System Access `createWritable` 原子写回用户磁盘原文件（来源：4.4）

- [ ] **无账号、无云同步**：换浏览器或清站点数据＝本地文档丢失，UI 已明示并提供"导出 JSON 备份"路径（来源：4.4 / FR-DOC-002）

- [ ] File System Access 句柄可持久化，但权限恢复须用户手势，重新授权提示不静默失败（来源：4.4）

## 5. 4.5 质量边界（5 条）
