# 用户指南 + 已知限制（TC-015）

## 快速开始

### 启动应用

```bash
# 在项目目录下
npx vite
# 或
npm run dev
```

浏览器打开 `http://localhost:5173`

### 创建简历

1. 点击顶部工具栏 **「新建」**
2. 选择：空白简历 / 基于模板 / 空白画板
3. 左侧组件库拖拽或点击添加组件
4. 画布上直接编辑内容

### 导出文件

- **导出 PDF**：工具栏右侧按钮，中文字体已嵌入
- **导出 Word**：可编辑副本，Word 中修改可能影响排版

### 导入已有简历

- 支持 `.docx` 和 `.pdf` 格式
- 系统会自动识别内容结构，逐项确认后导入
- 未识别内容进入待处理列表，不会丢失

## 已知限制（诚实告知，不夸大）

### 数据存储

- 简历数据仅存浏览器 **IndexedDB**，不上传任何服务器
- **清除浏览器数据会丢失所有简历**，请定期导出备份
- 不同浏览器之间数据不互通

### 导出限制

- **PDF**：中文必须使用内嵌 TTF 字体（已内置思源黑体/宋体）
- **DOCX**：是「可编辑副本」——Word 中修改可能影响排版，重要排版请回本产品调整
- 不承诺在所有办公软件中像素级一致

### 导入限制

- **不支持 OCR**：扫描件 PDF 无法识别文字
- 第三方 DOCX 导入为启发式识别，不保证 100% 还原原格式
- 复杂表格、文本框、浮动图片可能无法完整导入

### 功能边界

- 暗色模式：P0 不提供
- AI 建议：P1 后置
- 云端同步/账号：P1 后置（隐私路线）
- 流式排版模式：P1 后置

### 性能

- 5 页以上长文档布局可能变慢
- 移动端仅支持查看，编辑建议在桌面端使用
