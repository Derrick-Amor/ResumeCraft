液态玻璃规则

① 必须有色可折射。玻璃的实质是折射背后的东西。纯色底上做玻璃只会得到一块更白的方块，所以铺一层低饱和极光（蓝 / 青 / 紫，峰值透明度 0.24），纸面本身仍纯白不透明。

② 透明色只有一层，不叠渲染。默认按钮 rgba(255,255,255,.42)、主按钮 rgba(47,118,210,.14)、卡片 rgba(255,255,255,.5)，再加一根 1px 蓝边。不画镜面高光、不做色散彩边、不叠内阴影——那些模拟出来的光泽正是「假」的来源。

③ 模糊只负责柔化。backdrop-filter: blur(12px) saturate(140%) 的唯一作用是把背后的东西糊掉，不是去画玻璃。主按钮与默认按钮的区别只有颜色，没有光效。

④ 呼吸环是交互，不是材质。卡片 hover 时用伪元素画一圈 1px 蓝环，2.6 秒一周期只动透明度（0.45 → 1），不加外发光。系统开启「减少动态效果」时降级为常亮静态框。

⑤ 悬停是上浮不是放大。卡片 translateY(-6~8px) 配 1.008–1.012 缩放，缓动走弹簧曲线；同时抬 z-index，避免被邻居压住。

本稿与 Figma 原稿的 6 处差异

材质 原稿是哑光白面。改为液态玻璃 + 全蓝边框 + 悬停呼吸环，并为此铺了极光底——没有可折射的颜色，玻璃就不成立。纸面不参与玻璃化。
强调色 原稿强调色是墨绿 #4B7168。本轮把外壳整体转蓝 #2F76D2，墨绿降级为「纸面专用色」，仍保留在简历内容的竖条与意向行上。
纸面尺度 稿内纸面按 0.6 缩放绘制却标了 87%，87% 时整页装不进画布。本实现取 794 × 1123 真值 + 60% 视图，10.5 pt 正文才等于真实印刷尺寸。
状态栏分工 原稿把「第 1/2 页 · A4 · 87% · 已保存 · 3 处溢出」在同一条里重复出现两次。改为 画布条放页信息与缩放、状态栏放保存时间与溢出计数。
模板卡徽标 原稿「当前模板」与「已应用」同时出现在两张卡上。收敛为 只有当前使用的那张卡带徽标，其余保留语言标签与 A4 版式信息。
组件市场 原稿左栏是单列列表。改为 两列玻璃卡片网格，与模板市场同一套卡片语言：上浮 + 呼吸环 + 图标块；拖拽柄移到右上角、hover 才出现。
样式分三层加载：tokens.css（值）→ app.css（结构与组件）→ glass.css（材质与互动）。想退回哑光白面，注释掉 glass.css 一行即可。PDF 保持最终版式，Word 用于继续编辑；本作品为静态设计，文件解析、自动分页、按钮与实际导出均未接入功能。
