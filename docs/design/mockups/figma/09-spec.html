内容优先策略

白纸是视觉主角。两侧面板固定为白色，浅色工作台承托纸面；细线与低饱和墨绿只用于层级、选中与操作反馈。

错误草稿不污染纸面。邮箱这类正在编辑的无效值只留在面板里并标红，纸面保留上一次有效值，修复后再回写。

溢出分级处理。以数量、定位和三档策略（压缩该组件 / 压缩本页 / 暂不处理）呈现，不用恐吓性文案，并给出可读下限 10 pt / 1.40 倍。

中文与英文是两条内容轨。英文轨不含照片与政治面貌，成果以 Built / Implemented / Reduced / Led 等动作动词开头。

本次落地与 Figma 稿的 5 处差异

纸面尺度 稿内纸面按 0.6 缩放绘制却标了 87%，87% 时整页装不进画布。本实现取 794 × 1123 真值 + 60% 视图，10.5 pt 正文才等于真实印刷尺寸；顶栏右侧的百分比同步显示 60%。
警告色族 04 / 07 / 08 三屏都在用琥珀色，但原稿配色表未定义。补齐 warning #96611A（白底 5.23:1，警告底 4.78:1，两档均过 AA）。
选中框蓝 原稿选中框是未登记的蓝。正式收编为 selection #2F76D2，只用于画布选中框与画板描边，不参与按钮、标签、图表。
状态栏分工 原稿把「第 1/2 页 · A4 · 87% · 已保存 · 3 处溢出」在同一条里重复出现两次。改为 画布条放页信息与缩放、状态栏放保存时间与溢出计数，各出现一次。
模板卡徽标 原稿「当前模板」与「已应用」同时出现在两张卡上。收敛为 只有当前使用的那张卡带徽标，其余卡的语言标签与 A4 版式信息保留。
PDF 保持最终版式，Word 用于继续编辑；导出前检查内容、语言轨与分页。本作品为静态设计，文件解析、自动分页、按钮与实际导出均未接入功能。
