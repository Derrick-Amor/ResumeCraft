三版 UI 版图

同一份简历、同一个产品，三种结构：V1 去掉常驻面板，屏幕上只剩纸；V2 把面板变成浮起的大圆角卡片、把组件项放大到 56px；V3 压密度、收窄到 240px、主色只占 0.8%。三版的区别在面板的存在方式与密度，不在颜色。

V1 极简

单独打开

56px 图标轨道 + 48px 透明顶带；属性面板改成召之即来的浮卡，没有状态栏。屏幕上唯一有边界的东西是那张纸。

V2 圆润

单独打开

顶栏整条上暖色，左右面板变成 20px 圆角浮卡，组件项从 32px 抬到 56px 并配 tint 方块——把"能拖"写进形状里。

V3 工具

单独打开

240px 窄栏 + 28px 行高 + 单一 hairline，主色只占 0.8%，靠灰阶与字重分层。给每天用的人。
