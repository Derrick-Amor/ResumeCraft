## 0. 一句话结论

**原版是合格的实现基线，不需要推翻重来。** 但里面有 4 个阻断级硬伤必须先修——其中 H1（纸 DOM 内有 UI 元素）会在用户看不见的地方污染最终交付物（PDF）。

| 判定 | 内容 |
|---|---|
| **verdict** | **pass**（原版作为实现基线成立） |
| 工程量 | 11.2–13.7 人日（含 20% 联调缓冲 → **13.5–16.5**） |
| 最大资产 | mockup.css 引用 103 个 token **零硬编码色值**，与 tokens.css 名字集合 diff 为空 |
| 最大风险 | 3 屏 9 类 UI 元素住在纸 DOM 内，导出 PDF 会被印上去 |

## 2. 阻断级硬伤（必须先修）

### H1【P0】纸 DOM 内有 UI 元素——导出全会被印上去

**不只 08 角标。3 屏共 9 类 UI 元素住在 `.page` 内部：**

| 文件 | 行 | 元素 |
|---|---|---|
| 01-editor.html | 177 | `.page__guide` 页边距虚线 |
| 01-editor.html | 192, 202-205 | `.page__selected` + 4 个 `.handle` |
| 01-editor.html | 237 | `.insert-line` 插入线 |
| 06-layers-artboard.html | 244-248, 270-272 | 锁定 tag、说明文字 |
| 08-overflow-badge.html | 37-83 | `.page-badge-host` 全套角标 |
| 08-overflow-badge.html | 127-128 | 溢出红虚线 + 说明 |

**后果**：导出快照 diff ≠ 0 是必然。用户在编辑器里永远发现不了。

**修法**：Paper / CanvasOverlay 兄弟重构。所有 UI 元素迁 overlay + `data-export-hide`。视觉位置不变、信息量零损失。

> **这是唯一"屏幕上看不见、导出里全暴露"的错误。** PDF 是最终交付物，纸内混 UI = 产出物被污染。
> **如果只修一处，修这个。** 越晚越贵。

**代价**：0.6–0.9 人日

### H2【P0】794 纸宽在 1280 视口放不下

横向预算 264+794+280+16(滚动条) = **1354 > 1280**，差 74px。media query 收窄后仍差 50px。

mockup 用 `transform: scale(0.8)` + `margin-bottom:-230px` 掩盖——实测 `getBoundingClientRect().width` = **635.2 ≠ 794**，验收直接挂。

三证据表明这是**展示缩放不是设计决策**：负 margin 纯补偿、zoom 显示 85% 但 scale 是 0.8、`transform-origin: top center` 是截图构图手法。

**修法**：<1360 时面板改**覆盖**不挤压（BRIEF #1 原文）；`scrollbar-gutter: stable` 写死。scale hack 实现期一律删除。

**代价**：0.8–1.2 人日

### H3【P0】07 是居中 modal，违反"溢出永远贴底"

R1 三重裁决定死"溢出处理界面永远贴底"。理由原封不动适用：决策变量是几何后果（收回 7mm / 仍缺 11mm / 留白 62mm），离开出血行位置无法判断。

**代价**：0.3–0.4 人日（返工型——定位/交互/信息结构全要动）

### H4【P0】对比度 4 组破 AA（人命条款）

| 组合 | 对比度 | 出现处 |
|---|---|---|
| `text-tertiary #6e767e` on canvas `#e8ebed` | **3.85** ✗ | 01 标尺刻度 |
| `text-tertiary` on bg-subtle `#eff1f3` | **4.07** ✗ | 04 耗时、03 对照头 |
| `text-tertiary` on bg-page `#f9f9f9` | **4.38** ✗ | 02 计数 |
| `warning #a86400` on bg-subtle | **4.13** ✗ | 01/05 状态栏 |

tokens.css 只算了"on 白"4.52，没算在 subtle/canvas/page 底上的衰减。

**修法**：tertiary 压深一档（约 `#5f676f`）或按底色分变量。0.3–0.5 人日。

## 7. "再轻一点 / 再活一点"两个增量

> Amor 原话："过于正式和沉闷，稍微活力一点，不要用力过猛"。
> 两个增量都**保留原版全部功能、页面、字段**。

### 增量 A：只调 token（0.3–0.5 人日）

| 参数 | 现值 | 调整为 | 效果 |
|---|---|---|---|
| `--rc-color-primary` | `#107093` | `#0E7A9E` | 提饱和 4%、提明度 2%，更透亮 |
| `--rc-radius-lg` | 8px | 10px | 卡片更柔和 |
| `--rc-shadow-paper` | 0 8px 24px -6px | 0 12px 32px -8px | 纸"浮"得更轻 |
| `--rc-color-canvas` | `#e8ebed` | `#e3e7ea` | 画布加深，纸更突出 |
| `.btn:hover` translateY | -1px | -2px | 按钮浮起更明显 |
| `.entry:hover` translateY | -2px | -3px | 入口卡更有"活"感 |

**净改动**：7 个 token + 4 行 CSS。

### 增量 B：叠加微交互（0.8–1.2 人日）

| 新增 | 效果 | 人日 |
|---|---|---|
| 选中浮出工具条（复制/删除/上移/下移） | 选中即有操作入口 | 0.3 |
| 保存状态指示灯（脉冲橙点 → 绿点淡出） | "工具在运行"的生命感 | 0.1 |
| 模板卡磁吸（mini 图 scale(1.02) 视差） | 两层运动制造深度 | 0.05 |
| 通过项微勾动画（stroke-dashoffset） | "修完一个问题"的正反馈 | 0.15 |
| 角标弹入（scale 0.8→1，无回弹） | 新问题"注意我" | 0.05 |
| 入场编排 + 数值滚动 | 节奏感 | 0.45 |

### "活"的上限（提前说清）

能动的是**动效 + 圆角 + 密度 + 阴影**。颜色上做不出大文章——light-9 的 AA 约束卡死了饱和度。五区域骨架、794 纸宽、4.5:1 底线都是锁死的。

| 优先级 | 内容 | 人日 |
