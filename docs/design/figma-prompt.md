# 发给 Figma 的 UI 设计提示词

> 用法：直接整段复制发给 Figma（Make / AI 生成）。**不包含任何色值、变量名、间距数值**——视觉判断全部交给 Figma。
> 如果一次生成 8 屏效果不稳，先只发第 1 屏（主编辑器）+ 设计说明，满意后再发一句「沿用同一套视觉语言，补齐其余 7 个界面」。

---

## 提示词正文（复制这一段）

```
你是一名资深产品 UI 设计师。请为一款名为 ResumeCraft 的简历编辑与自动排版 Web 工具设计完整界面。

【产品一句话】
用户在浏览器里编辑结构化简历内容，系统负责排版、分页与溢出处理，最终导出可投递的 PDF 或可继续编辑的 Word。

【目标用户】
以中国大学生、应届毕业生、1–5 年职场人为主。界面语言为简体中文；简历内容以中文为主，同时要支持中英双语简历。

【设计方向】
简洁、现代、专业工具感，跟随当前设计趋势但保持克制。核心原则：**内容优先**——简历纸面是画面唯一的主角，界面（工具栏、面板、按钮）只在它外围做安静的容器，不要抢戏。
参考气质：Notion / Linear / Figma 这类编辑器型工具，而不是营销落地页。

【明确不要】
- 不要"紫粉渐变 + 发光 + 毛玻璃"这类一眼 AI 生成器的视觉痕迹
- 不要用 emoji 当图标；图标请用统一的一套线性风格图标
- 不要 Lorem ipsum、不要空占位框、不要"Welcome to..."式文案
- 不要过重的阴影堆叠、过大的圆角、过强的色彩对比轰炸

【画布与适配】
桌面端优先，主画布 1440×900；内容较长的界面（模板选择、导入向导）用 1440×1024。暂不考虑移动端。

【主界面骨架：五区域编辑器】（描述职责，样式你定）
- 顶部工具栏：文档名、模板切换、语言轨切换（中/英）、撤销重做、保存状态、导出按钮、导出前检查入口
- 左侧资源栏：Tab 切换「模板 / 组件 / 素材 / 页面」；模板 Tab 显示可拖入的模板卡；组件 Tab 显示可拖入的简历组件（基本信息、教育经历、项目经历、技能、自我评价等）
- 中央画布：A4 纸面悬浮在浅色工作台上，可见页边距辅助线与页数分隔，支持缩放与滚动
- 右侧属性面板：当前选中组件的可编辑字段（数字带单位、颜色、下拉、开关），校验失败时红字提示并可回滚
- 底部状态栏：页码、缩放比例、保存状态、溢出警告数量

【要交付的 8 个界面】

1. 主编辑器（五区域，如上）。默认展示一份已填写的中文简历，包含照片位、教育经历、两段项目经历、技能列表。

2. 模板选择面板：以侧边抽屉或全屏覆盖呈现。展示 4 套自设计模板的卡片（含缩略图、名称、适用场景标签、语言轨标识），顶部有搜索与筛选（按行业 / 职业阶段 / 语言）。当前使用的模板要有明确高亮。

3. 导入向导：分步流程（选择文件 → 解析中 → 预览确认）。核心是「人工对照」界面：左侧显示原 DOCX/PDF 的渲染预览，右侧显示识别后的结构化结果，逐条标注置信度与待人工确认的项（例如表格、文本框、浮动图片的还原情况）。要有"接受 / 修改 / 跳过"的操作。

4. 导出前检查对话框：列出检查结果，分三级——阻断（默认拦截导出，需用户明确确认才能继续）、警告、建议。每条要能看出问题位置与修复建议。演示一个"存在阻断项"的状态。

5. 空状态 / 首次引导：三个并列入口——从模板开始 / 导入已有简历 / 空白画板。每个入口有简短说明与图标。要让人第一眼知道该点哪个。

6. 图层面板 + 画板工具条：图层面板展示三层结构（背景 / 插图 / 组件），每项有可见性开关、锁定开关、名称；背景层默认锁定。画板工具条在画布上方或侧边，提供背景上传、背景色、纹理、插图插入。演示"选中一个组件"和"选中背景层"两种状态。

7. 溢出三阶段弹窗：当内容超出页面时弹出，提供三个选项——压缩该组件 / 压缩本页全部 / 暂不处理；若选择整体下移需提示"将导致页面出现空白"。文案要克制、不恐吓。

8. 溢出角标状态：右上角圆形感叹号角标，多处溢出时显示数量；鼠标悬浮或点击后弹出摘要浮层，列出问题清单并可跳转定位。

【实现与交付要求】
- 使用 Auto Layout 组织所有容器；组件化，可复用（按钮、输入框、模板卡、图层项、角标等）
- 使用 Variables 管理颜色、字号、间距、圆角，并在交付说明里列出这套体系
- 图标只用一套线性风格，视觉重量统一
- 每个界面都要用真实内容填满，不要留空结构
- 交付一份简短设计说明：配色思路、字体与字号层级、间距体系、图标来源、以及你如何体现"内容优先"

【真实内容要求】
界面文案与简历内容请用真实中文样例，例如：姓名「张明」，教育经历「华南理工大学 · 软件工程 · 2022.09–2026.06」，项目经历带具体动作与量化结果。英文轨简历要符合英文 CV 惯例（无照片、无政治面貌、动词开头）。
```

---

## 给 Amor 的使用建议

1. **分两次发更稳**：先让它做第 1 屏（主编辑器）+ 设计说明，风格满意后，再发「沿用同一套视觉语言，补齐其余 7 个界面」。一次要 8 屏容易风格漂移。
2. **先要设计说明再要界面**：让它先给配色/字体/间距体系，你认可后再生效——否则生成完再改视觉体系，返工更大。
3. **中文是硬要求**：Figma 的 AI 默认容易出英文占位文案，提示词里已经两次强调真实中文样例。如果它还是给英文，直接回一句"所有界面文案与简历内容改为简体中文真实样例"。
4. **产出了什么**：拿到 Figma 稿后，把设计说明（配色/字号/间距）发我，我来把它翻译成 `src/design/tokens.css`——这一步不能跳，否则 Figma 的稿和代码会各说一套。
